# Classification and Active Learning

This project compares learning methods on breast cancer and banknote classification datasets.

- Compare supervised, semi-supervised, and clustering approaches on the Breast Cancer Wisconsin dataset.
- Compare passive and active SVM learning on the banknote authentication dataset.
- Use repeated train/test splits to examine model performance and test error.

<a id="中文"></a>
# 分类与主动学习

本项目在乳腺癌和纸币分类数据集上比较不同的学习方法。

- 在 Wisconsin 乳腺癌数据集上比较监督学习、半监督学习和聚类方法。
- 在纸币认证数据集上比较被动学习与主动 SVM 学习。
- 通过重复划分训练集和测试集来观察模型表现与测试误差。
